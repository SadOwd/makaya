## 🌍 Vue d'ensemble

Makaya Energy est une plateforme complète de mobilité électrique comprenant:

- 🚕 **Makaya Ride**: Service VTC électrique avec Carbon Intelligence Engine
- 🚗 **Makaya Mobility**: Vente véhicules électriques + LLD + SAV
- ⚡ **Makaya Recharge**: Réseau intelligent de stations de recharge
- 📊 **Business Plan Global**: Dashboard investisseurs Série A

### 🎯 KPIs Clés Globaux
- **CA Annuel**: 1,746 Md FCFA
- **Clients Actifs**: 6,200+
- **Flotte VTC**: 6 véhicules électriques (78% utilisation)
- **CO₂ évité**: 1,855+ tonnes/an (Ride 847t + Recharge 1,008t)
- **Stations de recharge**: 6 (24 bornes, 22 actives)
- **Marge nette globale**: 42.8%

## 🚀 Installation

### Prérequis
- Node.js 18+ 
- npm ou yarn

### Étapes

```bash
# 1. Cloner le repository
git clone https://github.com/makaya-energy/app-makaya.git

# 2. Installer les dépendances
cd app-makaya
npm install

# 3. Lancer l'application
npm run dev

# 4. Ouvrir dans le navigateur
# http://localhost:5173
```

### Build Production

```bash
npm run build
npm run preview
```
