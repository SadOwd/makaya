🐛 RÉSOLUTION DE PROBLÈMES
══════════════════════════════════════════════════════════════════════════════

❌ Le script ne marche pas
  → Installez Node.js : https://nodejs.org
  → Vérifiez : node --version
  → Réessayez fusion-neon.bat

❌ Interface ne s'affiche pas
  → Testez d'abord index-demo.html
  → Ouvrez console navigateur (F12)
  → Vérifiez que React est chargé

❌ Animations lentes
  → Réduisez les particules (50 → 20)
  → Désactivez canvas sur mobile
  → Utilisez React.memo
