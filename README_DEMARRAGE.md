## ⚠️ En cas de problème

### Le script échoue ?
1. Vérifiez que les 3 fichiers `BusinessPlanJuridique_PARTIE*.jsx` existent
2. Vérifiez que le dossier `src/pages/` existe
3. Consultez le dossier `backup_*/` pour restaurer

### La page ne s'affiche pas ?
1. Vérifiez la console : `F12` dans le navigateur
2. Vérifiez le terminal npm pour les erreurs
3. Redémarrez : `Ctrl+C` puis `npm run dev`
